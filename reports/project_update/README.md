# Project update draft

One-page status update for **Policy-Controlled Optimizers under Biased Data Ordering**, dated November 13, 2026.

- `project_update_draft.pdf`: compiled draft.
- `main.tex`: editable LaTeX source.
- `aa228-jmlr2e.sty`: course template style.
- `momentum_block.pdf`: figure included by the source.

Adapted from the [course-linked proposal template](https://www.overleaf.com/read/ddwygbxkfzkv).
The table reports the original ten-ordering evaluation; the later extreme-ordering experiments are not included in this draft.

To compile with a LaTeX installation, run from this directory:

```sh
pdflatex -interaction=nonstopmode -halt-on-error -jobname=project_update_draft main.tex
```

Alternatively, upload `main.tex`, the style file, and the figure to Overleaf and select `main.tex` as the main document.
